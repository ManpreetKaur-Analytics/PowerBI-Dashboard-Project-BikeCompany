Power BI Dashboard Project - Data Analysis & Presentation

This project was developed during the Data Analysis and Presentation course, focusing on building three distinct dashboards—Operational, Tactical, and Strategic—using Power BI. Each dashboard type was designed with specific user needs and decision-making processes in mind, demonstrating an understanding of how to align data insights with business goals.

🧩 Project Highlights

✅ Key Tasks Performed:

* Created the semantic layer with appropriate table relationships and hierarchy.

* Cleaned, transformed, and prepared data by:

* Renaming and removing unnecessary columns.

* Creating calculated columns and measures.

* Summarizing and grouping data.

* Changing data types as required.

* Added business metrics such as:

* KPIs, targets, benchmarks, and achievement percentages.

* Inventory performance, revenue, work orders, and sales orders.

* Avoided common data modeling pitfalls and followed best practices in:

* Visual layout consistency

* Label clarity and color themes

* Data modeling optimization (star schema)

📊 Dashboards Overview

🔹 Operational Dashboard (1 Page)

Displays day-to-day KPIs such as:

1.Total Revenue

2.Total Inventory

3.Total Work Orders

4.Stock Coverage Days

5.Inventory vs Demand Gap

6.Sales Performance by Subcategory

Includes product-level insights into inventory surplus, shortfall, and order trends.



🔹 Strategic Dashboard (1 Page)

* Focused on high-level goals and performance against targets:

* Annual Revenue, Profit, and Inventory Turns with YoY comparisons

* Most and Least Turned Over Products

* Monthly Revenue vs Prior Year breakdown by category

* Profit trends by Month and Product Category



🔹 Tactical Dashboard (4 Pages)

Each page highlights specific organizational domains:

* Customer

* Employment

* Internal Processes

* Financial Performance

Power BI Desktop
